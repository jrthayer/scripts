# scripts

- **[goto](./goto/)** — A bookmark manager for quickly navigating to saved directories in PowerShell. Supports adding, removing, and listing bookmarks, with tab completion.
- **[shift-tab-blocker](./shift-tab-blocker/)** — Blocks the Shift+Tab combo system-wide (Shift and Tab still work alone). Tray icon to toggle it on/off and run at startup.
